# ระบบบัญชี — เว็บไซต์ส่วนตัว (จำกัดคนเข้าใช้งาน)

โค้ดทั้งหมดเขียนเสร็จแล้ว เหลือแค่คุณสร้างบัญชีฟรี 2 ที่ (Supabase + Vercel/Netlify) แล้วทำตามขั้นตอนด้านล่าง ใช้เวลาประมาณ 15-20 นาที ไม่มีค่าใช้จ่าย

## ภาพรวมระบบ
- **ฐานข้อมูล + ระบบล็อกอิน**: Supabase (ฟรี — เก็บได้ 500MB, ใช้งานได้สบายสำหรับครอบครัว)
- **โฮสต์เว็บไซต์**: Vercel หรือ Netlify (ฟรี)
- **การเข้าถึง**: ไม่มีปุ่มสมัครสมาชิกในเว็บ — คุณเป็นคนสร้างบัญชี username/password ให้แต่ละคนเองจากหลังบ้าน Supabase เท่านั้น คนอื่นเข้าเว็บไม่ได้ถ้าไม่มีบัญชีที่คุณสร้างให้

---

## ขั้นตอนที่ 1 — สร้างโปรเจกต์ Supabase (ฐานข้อมูล+ล็อกอิน)

1. ไปที่ [supabase.com](https://supabase.com) → กด **Start your project** → สมัคร/ล็อกอินด้วย GitHub หรืออีเมล
2. กด **New project** ตั้งชื่อโปรเจกต์ (เช่น `family-accounting`) ตั้งรหัสผ่านฐานข้อมูล (เก็บไว้ ไม่ต้องใช้บ่อย) เลือก Region ใกล้ไทย (Singapore) แล้วกด Create — รอประมาณ 1-2 นาที
3. เมื่อโปรเจกต์พร้อมแล้ว ไปที่เมนู **SQL Editor** (ไอคอนรูปเทอร์มินัล) → **New query**
4. เปิดไฟล์ `supabase/schema.sql` ที่แนบมาด้วย copy โค้ดทั้งหมดไปวาง แล้วกด **Run**
   - ขั้นตอนนี้จะสร้างตารางเก็บข้อมูลและตั้งกฎว่า **ต้องล็อกอินเท่านั้นถึงจะอ่าน/เขียนข้อมูลได้**
5. ไปที่เมนู **Authentication → Providers** → หา "Email" → ปิด **Enable email signups (self sign-up)** ให้เป็น OFF
   - นี่คือขั้นตอนสำคัญที่สุด: ปิดไม่ให้ใครสมัครเองได้ ต้องให้คุณสร้างบัญชีให้เท่านั้น
6. ไปที่เมนู **Authentication → Users** → กด **Add user → Create new user**
   - Email: ตั้งเป็น `ชื่อที่อยากให้ใช้ล็อกอิน@family.local` เช่น `mom@family.local`, `dad@family.local`, `puwit@family.local`
   - Password: ตั้งรหัสผ่านให้แต่ละคน (บอกรหัสนี้กับเจ้าตัวแยกต่างหาก)
   - ติ๊ก **Auto Confirm User** ด้วย (ไม่งั้นต้องยืนยันอีเมลซึ่งเป็นอีเมลปลอมที่ส่งจริงไม่ได้)
   - ทำซ้ำตามจำนวนคนที่จะให้เข้าใช้ (รวมตัวคุณเองด้วย)
7. ไปที่เมนู **Project Settings → API** → copy ค่า 2 ตัวนี้เก็บไว้:
   - **Project URL**
   - **anon public** key

---

## ขั้นตอนที่ 2 — ใส่ค่า Supabase ลงโปรเจกต์

1. คัดลอกไฟล์ `.env.example` เป็นไฟล์ชื่อ `.env`
2. แก้ค่าในไฟล์ `.env` ให้เป็นค่าจริงจากขั้นตอนที่ 1.7:
   ```
   VITE_SUPABASE_URL=https://xxxxxxxxxxxx.supabase.co
   VITE_SUPABASE_ANON_KEY=eyJxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   ```

---

## ขั้นตอนที่ 3 — รันทดสอบในเครื่องตัวเอง (ไม่บังคับ แต่แนะนำ)

ต้องมี [Node.js](https://nodejs.org) ติดตั้งไว้ก่อน แล้วเปิด terminal ในโฟลเดอร์นี้:

```bash
npm install
npm run dev
```

เปิด `http://localhost:5173` แล้วลองล็อกอินด้วย username/password ที่ตั้งไว้ในขั้นตอนที่ 1.6 (พิมพ์แค่ส่วนหน้า @ เช่น `mom` ไม่ต้องพิมพ์ `@family.local`)

## ขั้นตอนที่ 4 — เผยแพร่เป็นเว็บไซต์จริง (ฟรี)

### วิธีที่ง่ายที่สุด — Netlify Drop (ไม่ต้องใช้ Git)

```bash
npm run build
```

จะได้โฟลเดอร์ `dist/` ขึ้นมา → ไปที่ [app.netlify.com/drop](https://app.netlify.com/drop) → ลากโฟลเดอร์ `dist` ทั้งโฟลเดอร์ไปวาง → เสร็จ ได้ลิงก์เว็บทันที (เช่น `random-name-123.netlify.app`)

> ข้อควรระวัง: ถ้าอัปเดตโค้ดทีหลัง ต้อง build แล้วลากไฟล์ไปวางใหม่ทุกครั้ง ถ้าอยากให้อัปเดตอัตโนมัติเวลาแก้โค้ด แนะนำวิธีถัดไป

### วิธีที่ดีกว่าในระยะยาว — Vercel + GitHub

1. สร้างโปรเจกต์นี้เป็น GitHub repository (private repo ก็ได้ ฟรี)
2. ไปที่ [vercel.com](https://vercel.com) → สมัครด้วย GitHub → **Add New Project** → เลือก repo นี้
3. ในหน้า Environment Variables ใส่ `VITE_SUPABASE_URL` และ `VITE_SUPABASE_ANON_KEY` ตามค่าจริงของคุณ
4. กด Deploy — ได้ลิงก์เว็บถาวร ทุกครั้งที่ push โค้ดใหม่จะ deploy อัตโนมัติ

ทั้ง Netlify และ Vercel แผนฟรีเพียงพอสำหรับเว็บใช้ในครอบครัว/ธุรกิจเล็กสบายๆ ไม่ต้องผูกบัตรเครดิต

## เพิ่ม/ลบคนที่อนุญาตให้เข้าใช้งานทีหลัง

ไปที่ Supabase Dashboard → Authentication → Users
- **เพิ่มคน**: กด Add user ตามขั้นตอนที่ 1.6
- **ลบคน / เปลี่ยนรหัสผ่าน**: กดที่ชื่อผู้ใช้ในลิสต์ แล้วเลือก Delete user หรือ Reset password ได้เลย ไม่ต้องแก้โค้ด

## ข้อมูลจะหายไหมถ้าไม่ใช้นาน?
โปรเจกต์ Supabase แผนฟรีจะพักการทำงาน (pause) ถ้าไม่มีการใช้งานติดต่อกันเกิน ~1 สัปดาห์ แต่ข้อมูลไม่หาย แค่เปิดเว็บครั้งแรกหลังจากนั้นอาจช้าสักครู่ให้ระบบตื่นขึ้นมา

## ค่าใช้จ่าย
0 บาท ถ้าใช้โดเมนฟรีของ Netlify/Vercel (เช่น `yourapp.vercel.app`) ถ้าอยากได้โดเมนของตัวเอง (เช่น `บัญชี.com`) จะมีค่าจดโดเมนปีละประมาณ 300-500 บาทขึ้นอยู่กับผู้ให้บริการ — ไม่บังคับ
